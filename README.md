# Andriod Keyborad In KB

A minimal Android input method with a clean light theme, offline autocomplete, and a personal dictionary.

## Features
- Light and dark themes
- Dedicated number row
- Special characters page (?123 / #+=)
- **Offline autocomplete** — suggestion strip above keys with up to 3 word completions
- **Personal dictionary** — learns words you type (after 2 uses) and lets you add custom words manually

## Usage
Open the app, tap **Open keyboard settings**, enable **Andriod Keyborad In KB**, and select it in any text field.
Manage custom words in the app under **Custom words**.

## Word list
Bundled frequency list derived from [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (MIT License). Personal words stored locally only.
